# Happy English Club

אתר סטטי ללימוד אנגלית לילדים: משחקים, דפי עבודה, דפי צביעה ותצוגות של מערכי שיעור.

## פרסום אוטומטי באמצעות GitHub ו-Netlify

1. צרו מאגר GitHub **פרטי** בשם `happy-english-club`.
2. העלו אליו את תוכן התיקייה הזאת, כולל תיקיית `art`, הקובץ `index.html` והקובץ `netlify.toml`.
3. ב-Netlify בחרו `Add new project > Import an existing project > GitHub`.
4. בחרו במאגר שנוצר; בהגדרות הפריסה בחרו: Base directory ריק, Build command ריק, Publish directory `.`.
5. הפעילו Deploy. אחרי החיבור, כל commit לענף הפרסום מפעיל בנייה ופריסה, בהתאם להגדרות Netlify.

## חשוב

- זהו אתר דמו. אזור "ניהול תוכן" הנוכחי משתמש ב-localStorage והוא **לא** מערכת ניהול משותפת או מוגנת בסיסמה. אסור להסתמך עליו כדי לנהל תוכן חי באתר ציבורי.
- מערכי השיעור בתשלום אינם זמינים לרכישה. התצוגות הן הדגמות, ואין כעת אימות תשלומים או הגנה על קבצים.
- לניהול אמיתי נדרש בהמשך חיבור למערכת אימות, בסיס נתונים ואחסון קבצים עם הרשאות מתאימות; העלאת קבצים ועריכה יתבצעו דרך חשבון מנהל בלבד.
- קובצי האתר נשמרים ב-GitHub. תוכן שמשתנה דרך מערכת ניהול עתידית יישמר במסד הנתונים, לא בקובץ HTML.

## מבנה

- `index.html`: האתר והמשחקים
- `art/`: דפי צביעה בשחור-לבן
- `netlify.toml`: הגדרת פרסום Netlify

האתר לא דורש npm או שלב build בשלב זה.
